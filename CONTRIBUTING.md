# Contributing to Simple Interest Calculator

We welcome contributions from the community! Whether it's a bug report, a fix, documentation improvements, enhancements, or new ideas, your contributions help improve the project.

## How to Contribute

### 1. Bug Reports
If you find a bug, please open an **issue** in this repository with a clear description of the problem and steps to reproduce it. Include any relevant details about your environment or system.

### 2. Bug Fixes
If you want to fix a bug:
1. Fork the repository.
2. Create a new branch with a descriptive name, e.g., `bug-fix-description`.
3. Make your changes.
4. Commit your changes with a meaningful commit message.
5. Push the branch to your fork.
6. Open a pull request (PR) against the main repository.

### 3. Documentation Improvements
We welcome improvements to the documentation. Follow the same process as bug fixes:
- Update README.md or other markdown files.
- Make sure your changes are clear and helpful.
- Submit a pull request.

### 4. Enhancements
For new features or enhancements:
1. Open an issue to discuss your idea before implementation.
2. Once approved, create a new branch for your enhancement.
3. Implement the feature following the project's coding style.
4. Test your changes.
5. Submit a pull request with a clear description of the improvement.

### 5. Ideas
If you have suggestions for the project:
- Open an issue labeled `idea` or `enhancement`.
- Provide a detailed description of your idea.
- Engage in discussions with the maintainers and community.

## Pull Request Guidelines
- Make sure your PR is up-to-date with the latest main branch.
- Provide a clear description of what your PR does.
- Follow coding conventions and best practices.
- Be respectful and patient during review.

Thank you for contributing and helping improve the Simple Interest Calculator!
